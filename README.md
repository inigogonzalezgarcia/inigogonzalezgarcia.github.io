# inigogonzalezgarcia.github.io

My personal website: **https://inigogonzalezgarcia.github.io**

English by default with a Spanish switch. Plain HTML, CSS and JavaScript, generated by a Python script and published with GitHub Pages.

- **Home**: photos, latest blog stories, an interactive map of where I have worked, contact.
- **Journey**: eleven years in five stages, in numbers, and the toolkit (each tool links to its guide and its blog story).
- **Blog**: one story per GitHub project (38 projects) plus SysAdmin Desks, on what each one solves and how it was built.
- **IT guides**: 122 step-by-step guides in English and Spanish, from first steps to expert (four levels) and real cases by sector (hospitality, retail, healthcare, industry and financial services). Each guide links to its related blog stories, and some open a practice ticket in [SysAdmin Desks](https://sysadmindesksbyigg.pages.dev).
- **Services** (IGG-ICS career advice), **Resources** (33 ideas for IT professionals and the Tech Career Lab newsletter), **About**, **Links**, and the legal pages.

## How it is built

| Path | What it is |
|---|---|
| `*.html`, `blog/`, `guias/`, `sitemap.xml`, `assets/data.js` | Generated by `python3 src/build.py`. Don't edit them by hand |
| `src/build.py` | Career stages, map, toolkit, blog, guides, "Related" links between guides and stories, SEO titles and page assembly; runs security checks at the end |
| `src/pages.py` | Shared layout (header, menu, footer) and blog helpers |
| `src/posts.py` | Blog stories, one per repo (English and Spanish), with optional SEO title and description |
| `src/guides.py` | Guide levels and sectors, topics and the guides themselves (English and Spanish) |
| `src/legal.py` | Legal notice, terms and privacy texts |
| `src/sections/` | Page sections: hero, welcome, numbers, stages, toolkit, map, about, contact |
| `src/cities.json` | Cities on the map and what I did there |
| `src/config.json` | Photos, form endpoints, the booking link, the Cloudflare Turnstile site key and the Google Analytics measurement ID (all public values) |
| `src/make_map.py` | Writes `src/map.json`: Natural Earth 1:110m countries in Equal Earth projection |
| `src/make_og.py` | Social preview cards (`assets/og/`, 1200x630) and the Apple touch icon |
| `src/indexnow.py` | Tells Bing and other IndexNow engines which pages changed |
| `assets/` | CSS, JavaScript, photos, favicon, font (Inter Tight, SIL Open Font License) |

### Publishing

Only the sources need to be pushed. Two GitHub Actions do the rest:

- **Build site** (`.github/workflows/build.yml`): on a change in `src/` or `assets/style.css`, rebuilds every page with `src/build.py`, commits the generated files and sends the changed URLs to IndexNow.
- **OG images** (`.github/workflows/og-images.yml`): redraws the social preview cards when a story or the card script changes.

## Privacy

The font is self-hosted. Google Analytics 4 is loaded only after the visitor accepts it in the cookie banner (`assets/consent.js`, Consent Mode with everything denied by default); rejecting or withdrawing consent loads nothing and deletes the `_ga` cookies. Forms are protected with Cloudflare Turnstile and only send data when someone submits them. Details in the [privacy and cookie policy](https://inigogonzalezgarcia.github.io/privacidad.html).
