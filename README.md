# inigogonzalezgarcia.github.io

My personal website: **https://inigogonzalezgarcia.github.io**

English by default with a Spanish switch. Plain HTML, CSS and JavaScript, published with GitHub Pages.

- **Home**: photos, latest blog stories, an interactive map of where I have worked, contact.
- **Journey**: eleven years in five stages, in numbers, and the toolkit.
- **Blog**: one story per GitHub project, on how it was built.
- **About**, **Links** and **Store** (coming soon).

## How it is built

| Path | What it is |
|---|---|
| `*.html`, `blog/`, `assets/data.js` | Generated by `python3 src/build.py`. Don't edit them by hand |
| `src/build.py` | Career stages, map rendering and page assembly |
| `src/pages.py` | Shared layout (header, menu, footer) and blog helpers |
| `src/posts.py` | Blog posts, one per repo (English and Spanish) |
| `src/sections/` | Page sections: hero, numbers, stages, toolkit, map, about, contact |
| `src/cities.json` | Cities on the map and what I did there |
| `src/config.json` | Photos, the Formspree form ID and the Google Analytics measurement ID |
| `privacidad.html` | Privacy and cookie policy (EN/ES) |
| `src/make_map.py` | Writes `src/map.json` (not committed, it is already inside `index.html`): Natural Earth 1:110m countries in Equal Earth projection |
| `assets/` | CSS, JavaScript, photos, favicon, font (Inter Tight, SIL Open Font License) |

The font is self-hosted. Google Analytics 4 is loaded only after the visitor accepts it in the cookie banner (`assets/consent.js`, Consent Mode with everything denied by default); rejecting or withdrawing consent loads nothing and deletes the `_ga` cookies. The contact form posts to [Formspree](https://formspree.io), only when someone sends a message. Details in the [privacy and cookie policy](https://inigogonzalezgarcia.github.io/privacidad.html).
